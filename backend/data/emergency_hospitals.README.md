# 急诊院所快照維護

`emergency_hospitals.json` 是部分已核對名單，非全國完整名單、非即時收治資訊。

- 資格來源：[衛福部「全國重度級急救責任醫院急診即時資訊」第二節](https://dep.mohw.gov.tw/DOMA/fp-979-4112-106.html)。採用該節內容更新日 2026-02-24，不使用網站頁首日期。
- 核對日：2026-09-16。人工選取官方列名院所，與既有 `hospitals_5city.json` / `tainan_hospitals.json` 名称對照，共 24 家，涵蓋臺北、新北、桃園、臺中、臺南、高雄。
- 五都資料只採 name/address 層級座標，排除 district 層級。臺南沿用既有院所座標。座標代表院所位置，未驗證為急診入口；電話與地址沿用既有資料，未逐一電話確認。
- 台北市聯合醫院仁愛院區因名稱未精確對應而未收錄，不做模糊名稱配對。
- 提供定位時只列此快照中直線 30 公里內、最多 5 家；不代表全區最近 5 家。有縣市但無座標時依地址篩選，不顯示距離。
- 維護檢查期限暫設 2026-12-15；超過日期後停止提供快照院所，回傳 `needs_review`，前端保留官方名單入口。期限不是資格有效期。

## 更新步驟

1. 開啟官方名單，逐一確認院所名稱與資格；有更名或院區差異時核對地址，不直接模糊配對。
2. 確認院所地址、電話、座標來源；不以行政區中心取代院所位置。
3. 修改資料及 source_updated_on / verified_on / review_after，保留部分名單聲明。
4. 執行後端測試，人工檢查新增地點與導覽連結；更新核對紀錄。

檔案缺失、JSON 或日期無效會回傳 unavailable，避免宣稱當地沒有急診。

一般求助入口參考：[衛福部急救責任醫院名單](https://dep.mohw.gov.tw/DOMA/cp-2710-7581-106.html)、[衛福部 1925 安心專線服務說明](https://dep.mohw.gov.tw/DOMHAOH/cp-4906-54077-107.html)。前端求助電話與官方連結先呈現，院所查詢獨立載入，不等待資料庫或 AI 完成。
