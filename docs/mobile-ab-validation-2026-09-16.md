# Mobile A/B 相容性驗收

分支：feature/mobile-ab-compatibility；基於已推送的 A/B 提交 9d7eeec。使用者已要求提交並推送本輪手機端修復，提交狀態以 Git 紀錄為準。

## 已完成

- 移除手機端假定位；定位拒絕、失敗或 8 秒逾時回 null，可繼續問診。保留成功的真正零座標。
- 新增 22 縣市選擇，與座標互斥；晚到的定位不覆蓋手選縣市。
- 地圖只畫有效座標；沒有使用者位置時不畫使用者標記。結果用送出問診時的位置，歷史不套當前位置。
- 院所缺座標仍可用名稱地址導覽；距離需 provided_coordinates 標記才顯示。移除「最近」「專長最符合」的固定宣稱。
- 急症畫面先顯示 119、官方名單及急診搜尋；現有自傷／傷人旗標加心理支持入口。另查 emergency-resources，設定 5 秒逾時與取消舊請求，錯誤／空結果／過期不清除求助資訊。
- 會員保存失敗、缺 ID 不生成假成功摘要；只採用本次結果或明確載入的歷史 ID。
- 保留既有訪客本機摘要，明示未保存，取消硬編碼「一般風險／無高危險警訊」。
- 新問診、歷史切換及急症清除旧摘要。請求版本檢查避免重設或換帳號後晚到回應覆寫畫面。
- 不變更後端臨床規則、DB schema、套件版本或 API base URL 預設。

## 驗證結果

- 15 項工具／流程測試通過：座標、距離來源、地址導覽、8 類摘要狀態、定位拒絕／成功／逾時／錯誤。
- 3 項原生地圖元件樹測試通過：無座標、院所中心不冒充使用者位置、真實零座標及非法院所。
- 12 個 Expo Web 瀏覽器情境通過：拒絕／成功定位、手選縣市、保存失敗、會員缺 ID、訪客、急診 404／空結果／過期／成功、歷史摘要轉新問診、切換縣市舊請求隔離。
- Expo export 的 iOS、Android、Web 匯出成功（包含原生 Hermes bundle）。非 IPA/APK 原生編譯。
- git diff --check 通過。
- 測試未使用真實 DB／AI／病患資料；瀏覽器請求全部攔截，外部服務封鎖。

## 限制與實機工作

尚未使用實體手機或模擬器跑原生端到端測試。原生定位權限彈窗、地圖 SDK、外部導覽與撥號交由實機驗收，勿真的撥出求助電話作測試。

驗收重現輸入框 blur 時底部版面移動，造成送出按鈕第一次點擊失效；已改為隱藏內容但保留高度。最終 12 情境改用實際點擊送出按鈕重跑通過，先前 Enter 路徑亦通過。原生鍵盤／觸控仍須實機驗收。縣市選擇測試等待 Modal 關閉動畫完成。

急診名單沿用 B 的 24 家部分名單，非全國完整、非即時收治狀態。舊後端沒有新端點時顯示資源暫不可取得；完整功能需 A/B 後端先部署。

操作與實機清單見 mobile_app/tests/README.md。手機需使用可連到的測試後端位址；localhost 是手機自己。測試用環境變數只用於暫存匯出，未寫入專案設定。

Node 測試有既有 CommonJS package 中 ES module 偵測警告；Expo 有 NO_COLOR/FORCE_COLOR 提示，均不影響本輪結果。使用者原有 ingest.py、requirements.txt、dev.sh、webstart.command 保留。
